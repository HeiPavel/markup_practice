# Markup practice

## Motivation
***
A full implementation of a provided design into a web application using Next.js, React, Material UI, Tailwind CSS, and additional libraries. The project was created to practice building a responsive interface, developing reusable UI components, and integrating Material UI components.

## Technologies
***
* Next.js
* React
* TypeScript
* HTML5
* Tailwind
* Material UI
* React Hook Form
* React Hook Form Resolvers
* Zod
* Swiper

## Setup
***
* **git clone** {the url to the GitHub repo} or clone your own fork
* **cd** into the new folder
* **npm install**
* To run locally: **npm run dev**
